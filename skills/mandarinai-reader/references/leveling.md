# 分级指南 · HSK 1–9

动笔前读这份，写完对照检查。目标：词汇和语法卡在目标水平上下，让学习者「够一够能懂」。

HSK 用的是 2021 年版三阶九级（初等 1–3 / 中等 4–6 / 高等 7–9）。下面按常用的「初 / 中 / 高」三档给可操作的边界——分级是判断，不是查表，拿不准就降级或把词放进生词表。

## 初级 · HSK 1–3

学习者刚起步，靠高频词和短句理解。

- **词汇**：日常高频词为主——你、我、家、吃、喜欢、今天、因为、可以。抽象词、书面词尽量不用。
- **语法**：
  - 基本语序「主 + 谓 + 宾」「主 + 时间 + 地点 + 动作」。
  - 简单的「了 / 在 / 过」、能愿动词（想 / 要 / 会 / 能 / 可以）、简单连词（和 / 但是 / 因为…所以）。
  - 避免：把字句 / 被字句的复杂用法、多重嵌套从句、书面连词（尽管 / 然而 / 从而）。
- **句长**：每句尽量 8–15 字，一句一个意思。多用短句和句号。
- **篇幅**：150–300 字。
- **生词**：超纲词控制在很少，每个都进生词表，正文里不连续堆。

## 中级 · HSK 4–6

能读连贯段落，接受一定的抽象和书面表达。这是默认档（HSK 3–4）。

- **词汇**：日常 + 常见抽象词、双音节书面词——发展、影响、提供、观点、其实、不过、虽然。成语点到为止，用了就进生词表。
- **语法**：
  - 复句常态化：虽然…但是、不仅…而且、即使…也、不管…都、之所以…是因为。
  - 把字句、被字句、比较句（比 / 不如 / 越来越）、结果 / 程度补语可以用。
  - 仍避免：过于书面的连词堆叠、长难句一逗到底。
- **句长**：15–25 字常见，允许一两个复句，但别让从句套从句。
- **篇幅**：300–600 字。
- **生词**：8–15 个，挑真正超纲、又对理解关键的词。

## 高级 · HSK 7–9

接近母语阅读，能处理书面语、成语、长句和抽象论述。

- **词汇**：书面语、专业词、成语俗语、近义词辨析都可用。仍为生僻专名 / 术语提供生词表。
- **语法**：完整的书面语句式、长句、修辞（排比、设问）、语气与语体的切换都可用。
- **句长**：自然书面语长度，但仍要清晰，不为难而难。
- **篇幅**：600–1000 字。
- **生词**：挑成语、专业词、文化词，重在辨析和用法，不只给字面义。

## 通用检查（写完逐条过）

1. **逐句扫一遍**：有没有明显超过目标水平、又没进生词表的词？有 → 换掉或补进生词表。
2. **句子长度**：有没有一逗到底的长句？初 / 中级 → 拆短。
3. **语法越界**：用了目标水平不该出现的句型？降级改写。
4. **翻译腔**：哪句读起来像从英文翻来的？重写成自然中文。
5. **拼音**：标题和生词表的拼音声调对不对？标准声调标注（mā / má / mǎ / mà），不用数字调。
6. **可读性**：合上原素材，单读这篇文章，目标水平的学习者能从头读到尾、读懂大意吗？不能 → 再降一档。
