# 模具：诗词注音（-p）

## 核心信条

**拼音悬于字上，译文垫于句下——一张卡就是一节课。**

神：学习者一眼三层——抬眼是读音，正视是汉字，低眼是意思。三层各司其职，汉字永远是主角。

形：与 `-b` 同源的和紙暗框美学。标题居中如碑额，诗行居中如碑文，拼音小写悬顶，译文斜体垫底。**对称居中在这里是正确性**——诗是对称的，卡也是。

## 步骤 1：读取规范与模板

1. Read `references/pinyin-annotation.md` —— 拼音与译文的硬规则（小写、声调符号、多音字核对、译文默认英文）
2. Read `assets/poem_template.html`

模板变量：

| 变量 | 内容 |
|------|------|
| `{{POEM_TITLE}}` | 诗题（如 `静夜思`） |
| `{{POEM_AUTHOR}}` | 朝代 · 作者（如 `唐 · 李白`）；无作者可留空字符串 |
| `{{POEM_BODY}}` | 诗行块序列（见步骤 3） |
| `{{HANZI_SIZE}}` / `{{PINYIN_SIZE}}` / `{{GLOSS_SIZE}}` | 三层字号数值（不带 px），查步骤 2 表 |
| `{{LINE_GAP}}` | 行块间距数值（不带 px），查步骤 2 表 |
| `{{SOURCE_LINE}}` | 来源线 HTML 或空 |
| `{{CUSTOM_CSS}}` | 额外 CSS（一般留空） |

## 步骤 2：解析内容，选排版档位

### 2.1 拆解

从输入中提取：诗题、作者（朝代·姓名）、诗句、目标译文语言（用户未指定 → 英文）。

### 2.2 选行排方式

- **≤ 4 个半句**（绝句、名句、对联）：一个半句一行，每行配一条译文
- **5-8 个半句**(律诗、词的上下阕）：**一联一行**（如 `国破山河在，城春草木深。`），每行配一条整联译文
- **> 8 个半句**（长诗、歌词）：切成多张卡（每张 ≤ 4 行块），文件名加 `_1`、`_2` 序号；或与用户确认只取节选

### 2.3 字号档位表（基线，可上下浮动 10%）

| 行排形态 | 每行单元数* | HANZI | PINYIN | GLOSS | LINE_GAP |
|----------|------------|-------|--------|-------|----------|
| 五言半句 ×4 | ≤ 6 | 84 | 26 | 30 | 56 |
| 七言半句 ×4 | ≤ 8 | 76 | 24 | 29 | 52 |
| 五言联句 ×4 | ≤ 12 | 56 | 18 | 24 | 46 |
| 七言联句 ×4 | ≤ 16 | 44 | 15 | 21 | 42 |
| 词/歌词 4-6 行（不齐言） | 按最长行 | 60-68 | 20 | 25 | 40 |

\* 单元 = 汉字 + 行中标点。行末悬挂标点不计入宽度。

宽度硬约束：行宽 ≤ 860px（画布 1036 - 左右 padding 176）。估算：单元数 × HANZI × 1.28 ≤ 860，超了就降档。

## 步骤 3：写诗行块

每行一个 `.line` 块：拼音汉字行 + 译文行。

```html
<div class="line">
  <div class="hanzi"><ruby>床<rt>chuáng</rt></ruby><ruby>前<rt>qián</rt></ruby><ruby>明<rt>míng</rt></ruby><ruby>月<rt>yuè</rt></ruby><ruby>光<rt>guāng</rt></ruby><span class="punct-hang">，</span></div>
  <div class="gloss">Moonlight spreads before my bed,</div>
</div>
```

- 拼音标注严格按 `pinyin-annotation.md`：逐字 `<ruby>`、全小写、声调符号、多音字逐个核对
- **行末标点**用 `<span class="punct-hang">`（悬挂到右边距，汉字块保持光学居中）；**行中标点**（联句中间的逗号）用 `<span class="punct">`
- 需要点睛的字/词可用 `<span class="shu">` 染朱砂红包住 `<ruby>` 整字，每张 ≤ 1 处
- 译文行遵循目标语言自身大小写规范（小写只约束拼音）
- 联句译文控制在约 90 字符内：超出会折行，折一行可接受，两行以上必须精简译文

写入：`/tmp/mandarinai_cast_poem_{name}.html`

## 步骤 4：自检

先过 `pinyin-annotation.md` 的注音自检，再过本模具项：

- [ ] 字号档位与行排形态匹配，行宽估算 ≤ 860px？
- [ ] 行末标点用 punct-hang、行中标点用 punct？
- [ ] 标题/作者/诗行全部居中（-p 豁免"禁居中"规则）？
- [ ] 字体：汉字 Noto Serif SC、拼音 Noto Sans SC、译文 EB Garamond 斜体？
- [ ] 朱砂高亮 ≤ 1 处？

## 步骤 5：截图并核验

```bash
node assets/capture.js \
  /tmp/mandarinai_cast_poem_{name}.html \
  ~/Downloads/{name}.png \
  1080 1440
```

**截图后必须 Read 生成的 PNG 目检**（这是 -p 独有的强制步骤，因为拼音错误和布局塌陷肉眼立辨）：

1. 最后一行译文与左下署名是否碰撞？碰了 → 降一档字号或减 LINE_GAP，重截
2. 逐行核对拼音：有无漏标、错位、多音字错读？
3. 译文语言、行数与诗行是否一一对应？

## 步骤 6：交付

报告文件路径。一句话说明行排方式（半句/联句）和多音字决策（如有）。

## 禁忌

- 禁：整句拼音塞一个 `<rt>`（必须逐字）
- 禁：拼音大写、数字调、v 代 ü
- 禁：跳过截图后的 PNG 目检
- 禁：诗行左对齐（本模具对称居中是正确性，不是 AI 痕迹）
- 禁：译文比汉字行更抢眼（字号/颜色反转层级）
- 禁：改画布尺寸（1080x1440 小红书规范）
