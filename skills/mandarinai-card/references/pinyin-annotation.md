# 拼音注音规范（跨模具共享）

任何模具（`-p` 诗词卡为主，`-l`/`-b`/`-m` 遇到"加拼音"需求时同样适用）输出带拼音的中文内容时，必须遵守本规范。

## 1. 标注格式

逐字标注，用 HTML 原生 `<ruby>`，拼音自动居中于汉字上方：

```html
<ruby>床<rt>chuáng</rt></ruby><ruby>前<rt>qián</rt></ruby><ruby>明<rt>míng</rt></ruby>
```

- **一个汉字一个 `<ruby>`**，一个 `<rt>` 一个音节。不要把整句拼音塞进一个 `<rt>`
- 标点**放在 `<ruby>` 外面**，不注音
- Chromium 会在拼音比汉字宽时（如 chuáng、shuāng）自动撑开字距，无需手动处理

## 2. 拼音书写规则

- **全部小写**。句首、专有名词（李白 → lǐ bái）一律小写，无例外
- **声调符号**（ā á ǎ à），禁止数字调（a1）、禁止不标调
- **ü 写作 ü**，禁止用 v（女 → nǚ）
- 轻声不标调：的 de、了 le、吗 ma、们 men
- 隔音符按正词法：逐字标注时天然规避，无需 '

### 变调标注（学习者友好约定）

- **一、不 按实际读音标**：一片 yí piàn、一夜 yí yè、不是 bú shì、不对 bú duì
- **上声变调不改标**：你好 nǐ hǎo（不写 ní hǎo）——这是教材通行标准

## 3. 多音字（错一个字就砸卡，逐字核对）

生成后必须逐字复查多音字，按语境定音。高频雷区：

| 字 | 常见读音 | 判断 |
|----|---------|------|
| 行 | xíng / háng | 行走 xíng；银行/一行 háng |
| 还 | hái / huán | 还是 hái；归还 huán |
| 重 | zhòng / chóng | 重量 zhòng；重复/重逢 chóng |
| 长 | cháng / zhǎng | 长江 cháng；生长/长安的"长"仍是 cháng |
| 得 | dé / de / děi | 得到 dé；跑得快 de；得去 děi |
| 地 | dì / de | 大地 dì；慢慢地 de |
| 教 | jiāo / jiào | 教书 jiāo；教育/使令义"教"（古诗中常 jiào）|
| 骑 | qí | 现代统读 qí（旧读 jì 不再用）|
| 斜 | xié | 现代统读 xié（"远上寒山石径斜"按今音标 xié）|
| 看 | kàn / kān | 看见 kàn；看守 kān |
| 曲 | qǔ / qū | 歌曲 qǔ；弯曲 qū |
| 数 | shù / shǔ / shuò | 数字 shù；数一数 shǔ |

古诗按**现行普通话审音**标注（教材标准），不用中古拟音、不用叶韵改读。

## 4. 译文行规则

- 位置：**每行诗句/句子的下方**，独立一行
- 语言：**默认英文**；用户指定其他语言（西/日/韩/法等）则照办，规则不变
- 视觉上从属于汉字行：字号更小、颜色更柔、拉丁文用衬线斜体（模板已定义 `.gloss`）
- 译文遵循目标语言自身的大小写规范（英文句首大写照常）——**全小写只约束拼音**
- 译得忠实、简洁、有诗感；不逐字硬译，也不自由发挥到偏离原意

## 5. 出厂自检（截图前必过）

格式项由 `scripts/validate-pinyin.py` 强制执行——填好模板后先跑它，exit 0 才继续：

```bash
python3 scripts/validate-pinyin.py <填好的卡片 HTML>
```

它覆盖：每个汉字有且只有一个音节、拼音全小写、声调符号（拒绝 chuang2）、ü 不写作 v、
标点在 `<ruby>` 外、每行有译文、行宽 ≤ 860px。

**校验器看不见的，必须自己核对**：

- [ ] 逐字核对过表中多音字及其他存疑字（读音对不对，脚本不知道）？
- [ ] 一/不 按实际读音标（yí piàn / bú shì）？
- [ ] 轻声该不标调的没标、该标调的没漏（脚本只能 warning）？
- [ ] 译文忠实、简洁，语言与用户要求一致？
